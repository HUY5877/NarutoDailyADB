# 游戏内确认页粘贴 token

## 目标与设计

游戏拉起 `AgentActivity` 时直接显示输入框，允许粘贴原始 `access_token` 或完整 `auth://tauth.qq.com/` 回调地址，读取云端对应授权，核对账号后点击确认返回游戏。已有手动选择账号的流程继续可用。根因是上一版只修改了 `MainActivity`。

完整回调仅用于严格解析和匹配身份，再使用当前网站会话查询已有云端记录；不将粘贴时间视为捕获时间，不离线重建授权有效期。界面明确需要先登录保存该授权的网站账号。此设计落实用户已有手动粘贴登录要求，不增加新的数据库或登录协议。

## Global Constraints

- 只在现有 test 工作树修改，提交信息中文，不动 main。
- 仅信任火影忍者现有 RequestPolicy 调用；返回凭据前再次检查来源、会话和有效期。
- 使用当前网站账号解析云端授权，完整回调不得覆盖云端记录或重置有效期；回调中的 openid 必须与解析结果一致。
- 输入修改、取消、离开页面、会话变化后，旧请求不得恢复授权或启用确认。请求成功后必须由用户明确确认。
- 不记录、不打印真实 token/Cookie；输入不进入保存状态或持久化，退出页面时清空。保留现有安全输入设置。
- 保留已有选择账号入口；只更新上号器 APK，同签名覆盖安装保留登录状态。

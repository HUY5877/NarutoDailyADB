# 上号器互斥登录模式

## 用户要求

直接输入与云端选择是两条独立路径，一次只能使用一条。用户最终明确只要完整 callback_url 登录，取消 Token 入口。直接输入不能再作为 HUY 云端查询条件。

## 已确定设计

- 页面顶部用单选模式「回调 URL 登录」「云端账号登录」，初始默认 URL 登录；不再提供 Token 输入或格式切换。
- 仅显示当前模式的控件。模式切换立即清空输入、已加载授权、列表选择和待确认状态，作废旧网络响应。持久化仅可保存模式偏好及原有云记录 ID，不保存直接凭据。
- 直接路径不要求网站会话、不调用任何接口、不读取抓号器缓存或云记录。用户已明确禁止调用额外接口。仅接收原始完整回调 URL，不得凭空生成身份、支付凭据或真实有效期。
- 云端路径登录原网站账号、读取账号列表、显式选择一项后读取授权并确认，保留原有效期与会话/调用方校验。
- 主页面同样拆分模式；URL 模式提供打开游戏入口，提示到游戏 QQ 确认页粘贴；云端模式保留列表与选择。这样直接凭据不跨 Activity 持久化或隐式传递。
- 游戏结果仍只能返回可信火影忍者调用者，必须明确点击确认。编辑、模式切换、停止/重建、适用的网站会话变化后不能恢复旧授权。

## 直接 Token 的核实

静态检查当前安装游戏的 QQ SDK 确认，成功回传必须包含 access_token、openid、expires_in；FeedConfirmListener 要求 QQToken.saveSession 成功，缺少 expires_in 会返回持久化失败。pay_token 是否为游戏业务必需尚未证实，保留输入中的原值。用户明确不调用额外接口后，停止接口核实并采用纯本地解析。

因此裸 access_token 无法独立补齐必需字段，用户明确取消 Token 功能。完整 URL 没有原始时间时，不把粘贴时间保存为捕获时间、不声称已知实际到期日；仅保留传入有效期并扣除用户在当前页面等待的时间，最终有效性由游戏验证。有原始授权时间时保持真实截止时间。

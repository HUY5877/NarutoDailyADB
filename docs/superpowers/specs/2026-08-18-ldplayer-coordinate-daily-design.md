# 雷电模拟器纯坐标日常脚本设计

## 目标

在雷电模拟器 9 中，通过 ADB 固定坐标操作《火影忍者》手游，依次尝试完成登录与签到、领取体力、免费招募、一次丰饶之间手动战斗。第一版不使用图像识别、OCR、内存读取、注入、改包或反检测技术。

## 前提与限制

- 雷电内部安卓分辨率固定，运行期间不旋转屏幕。
- 坐标基于安卓画面，不基于 Windows 桌面位置。
- 默认 ADB 路径为 `E:\雷电模拟器\leidian\LDPlayer9\adb.exe`。
- 游戏界面、弹窗顺序和网络加载时间变化都可能导致纯坐标流程失效。
- 脚本不处理验证码、人脸验证、付费或购买确认。
- 在线游戏自动化可能违反游戏服务规则，账号风险由使用者自行评估。

## 组件

1. `naruto_daily/adb_client.py`：连接设备并执行点击、滑动、返回和分辨率查询。
2. `naruto_daily/config.py`：加载并校验 JSON 配置。
3. `naruto_daily/runner.py`：执行动作序列、超时与 dry-run。
4. `naruto_daily/tasks.py`：定义签到、体力、免费招募和丰饶之间动作序列。
5. `naruto_daily/cli.py`：提供设备检查、单任务及全流程命令。
6. `config.example.json`：保存分辨率、坐标、等待时间和战斗循环参数示例。

## 执行流程

启动时检查 ADB 路径、在线设备和安卓分辨率。若当前分辨率与配置不一致，立即停止。默认先以单任务模式调试；全部坐标校准后才运行全流程。

任务由点击、滑动、返回和等待动作组成。丰饶之间战斗使用定时循环：移动、普攻、两个技能和奥义，并设置最大持续时间。脚本从调用者指定的预定页面开始；纯坐标版本不判断当前游戏页面。

## 安全措施

- `--dry-run` 只打印动作，不发送输入。
- 全流程启动前倒计时五秒，允许用户按 Ctrl+C 取消。
- 单任务动作数不超过 100，总运行时间不超过 300 秒。
- 示例配置不包含充值、购买或金币确认坐标。
- 中断或 ADB 命令失败后立即退出，不自动从未知页面恢复。
- 第一版不提供无人值守定时启动。

## 验证

自动化测试使用假的 ADB 命令执行器，验证命令、配置校验、dry-run、超时和任务编排。真实设备验收依次验证设备枚举、分辨率、一次安全点击、四项单任务，最后才验证全流程。
